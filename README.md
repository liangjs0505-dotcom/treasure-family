# Treasure Family Frontend（宝藏之家前端）

超市进销存和结账。顶栏只有数据看板、货物录入、结账。库存从看板上的货物管理进去。

- 货物录入先扫条码。售价、进价和新货入库数量必须大于 0。单位、分类和库存筛选用 Ant Design 下拉。
- 从货物管理点编辑，保存或取消后回到货物管理。
- 结账按条码加入账单，确认时选现金或刷卡，之后才扣库存。切到别的页时，当前账单还在。
- 流水与利润按交易数量分页，不按笔数。一页累计超过 50 个就翻页，一笔不从中间切开。从这里去结账再回来，当天明细会重新拉取。
- 畅销榜前三名是金银铜奖牌，默认按累计销量，也可以按总利润排。第 4 名起是灰色圆圈。
- 注册用户名 3 到 32 位，可以用中文、字母、数字和下划线。令牌被删掉或接口返回未登录时回到登录页。输错密码不会清掉已经登录的令牌。

本地运行：

```bash
npm install
npm run dev
```

开发地址：http://localhost:5173/

货物、结账和流水都请求后端 `http://localhost:8080`。开发改动只放在 `feat_v1`，不要直接推到 `main`。
